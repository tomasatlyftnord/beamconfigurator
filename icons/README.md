# Appikoner

Motivet är ett lyftok med central lyftögla och två lastkrokar i projektets marinblå/gula färgtema. Ikonen skapades för projektet och har exporterats till vanliga ikonstorlekar utan ändring av motivet.

- `../favicon.ico`: Windows-/webbläsarikon med 16, 32, 48, 64, 128 och 256 px i samma fil. Välj denna när du byter ikon på en Windowsgenväg.
- `favicon-32.png`: PNG-favicon för webbläsarfliken.
- `app-icon-192.png` och `app-icon-512.png`: appikoner för webbmanifestet.
- `app-icon-maskable-512.png`: separat variant med extra marginal för rundad/cirkulär beskärning på enheter som använder maskbara ikoner.
- `apple-touch-icon.png`: 180 px-ikon för Apples hemskärmsgenvägar.

Behåll ikonmappen och `favicon.ico` tillsammans med resten av projektet. Webbläsaren kan lagra gamla favicons i cache; en befintlig skrivbordsgenväg kan också behöva tilldelas den nya ikonen manuellt.
